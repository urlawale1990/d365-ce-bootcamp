# Capstone, assessment and certification path

Learners graduate with a working Contoso solution, a portfolio and a clear exam plan. Note that the old CE exams many courses still advertise (MB-210, MB-910, MB-280, PL-200) are now retired, so this course targets the current credentials.

### Final capstone (Week 16)

Learners assemble their 15 weekly Northwind capstones into one finished, deployed solution and deliver:

- [ ] A requirements list as user stories with a fit-gap column (standard / configure / extend)
- [ ] One exported solution containing all custom tables, forms, views, business rules, BPF, flows and apps
- [ ] A security matrix and at least 3 test users with different roles
- [ ] A working sales process (lead to invoice) and support process (case to resolution with SLA)
- [ ] One Power Automate flow and one Power BI report
- [ ] A 10-page functional design document and a 1-page user guide
- [ ] A 15-minute live demo presented to the class in Week 16

### Final capstone rubric

Scored out of 100, then weighted into the course grade (capstone solution 35% + demo 15%). Pass = 70.

| Criterion | Points | Excellent (full marks) | Competent (about 70%) | Needs work (below 50%) |
| --- | --- | --- | --- | --- |
| Requirements and analysis | 20 | BRD, stories and fit-gap are complete, prioritised and traceable via the RTM | Most requirements captured; some stories lack clear acceptance criteria | Requirements vague or missing; no fit-gap reasoning |
| Solution design | 20 | ERD, security design and FRD match what was built; standard features used before custom | Design mostly matches the build; one or two unjustified customisations | Design and build disagree; heavy customisation where standard features fit |
| Build quality and solution management | 25 | All components in a named solution with publisher prefix; deploys as managed to Test cleanly; flows use environment variables | Deploys with minor fixes; a few components outside the solution | Built in the Default solution or fails to deploy |
| Testing, data and documentation | 15 | Test scripts executed with defects logged in Azure DevOps; clean data import; user guide usable unaided | Tests run but not all traced; guide needs help | Little evidence of testing or documentation |
| Presentation and consulting | 20 | Clear 15-minute demo told as a business story; handles “Northwind board” questions confidently | Demo works but is feature-led rather than business-led | Demo breaks or cannot answer basic questions |


### Assessment

| Component | Weight | When |
| --- | --- | --- |
| Weekly homework and Northwind capstones | 30% | Weeks 2–15 |
| Phase checkpoint quizzes (25 questions each) | 20% | Weeks 3, 6, 11, 14 |
| Capstone solution and documentation | 35% | Week 16 |
| Capstone demo and Q&A | 15% | Week 16 |

Pass mark 70%. Learners who pass receive a course certificate; those below 70% get a resubmission window of 2 weeks.

### Certification path (current as of October 2026)

| Order | Credential | Exam | Why |
| --- | --- | --- | --- |
| 1 | Dynamics 365 Customer Service Functional Consultant Associate | MB-230 | Still live; maps directly to Weeks 2–10 |
| 2 | Dynamics 365 Sales AI Consultant Associate | AB-210 | Newer Sales credential that replaced the retired Sales path |
| 3 (optional) | Intelligent Applications Builder Associate | AB-410 | Power Platform builder skills from Weeks 4–6 and 12–14 |
| 4 (optional) | Dynamics 365 Contact Center AI Engineer Associate | AB-250 | For learners heading into omnichannel / contact centre work |

Verify exam details on Microsoft Learn before each cohort starts; Microsoft retired several business-apps exams in 2025–26. Sources: [retired exams list](https://learn.microsoft.com/credentials/support/retired-certification-exams), [practice assessments list](https://learn.microsoft.com/credentials/certifications/practice-assessments-for-microsoft-certifications).

### Job readiness (woven through Weeks 14–16)

- CV and LinkedIn rewrite around the capstone, with screenshots and the demo video
- 2 mock functional consultant interviews: one scenario-based (“a client wants X, how would you configure it?”), one behavioural
- A hands-on interview test, similar to the CRM Interview Hands-On Test already in your files
- Guidance on first roles: junior functional consultant, CRM administrator, business analyst (Dynamics), support consultant
