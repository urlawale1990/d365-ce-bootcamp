# As-is / to-be process map (Week 5)

**Format:** swimlanes per role, start/end events, tasks, decisions, systems used. One map per process.

**Contoso example — service request, as-is:** customer phones → receptionist writes on paper → emails service manager → manager phones technician → no record of resolution.

**To-be:** customer phones or emails → agent creates case in D365 → routing rule assigns queue → technician updates case on mobile → case resolved, survey sent automatically.
