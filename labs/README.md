# Contoso lab sheets

Step-by-step guided labs for **Contoso Home Services**, one sheet per week. Each sheet has the Saturday and Sunday labs, checks to tick off, and the week's homework. Your Northwind capstone task is in each [weekly guide](../weeks/).

Everything you build from Week 4 onwards goes in the **Contoso Configuration** solution (publisher prefix `cnt`), never the Default solution.
