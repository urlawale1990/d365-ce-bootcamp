# Week 0 — Onboarding

A short online session so Week 1 starts with learning, not admin. Run it on the Sunday before the course or as a recorded video plus 20-minute live Q&A.

| Time | Activity | Outcome |
| --- | --- | --- |
| 0:00–0:10 | Welcome, course map, how weekends and capstones work | Learners know what is expected each week |
| 0:10–0:25 | Create a personal Microsoft account (not a work one) and a [Microsoft Learn profile](https://learn.microsoft.com/en-us/users/); link it to a certification profile | Exams and badges are kept for life, even if they change jobs |
| 0:25–0:35 | Join the class channel (Teams or WhatsApp); share the course Microsoft Learn collection with all readings in order | One place for questions, one place for reading |
| 0:35–0:45 | Week 1 checklist: phone for MFA, payment card for verification, tenant name chosen, Edge or Chrome updated | No blockers on trial-setup day |
| 0:45–0:60 | Expectations and study plan: 4 live hours + 3–4 self-study hours per week; LinkedIn headline starting point | Learners commit to a weekly study slot |
